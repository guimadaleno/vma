# Privacy

The vma plugin is one skill: instructions Claude Code reads. It collects,
sends and keeps nothing, and neither it nor its author receives any data.

The skill has Claude run the `vma` command on your computer. vma talks only
to VirtualBox on that computer and makes no network request. What Claude
sees through it, such as a picture of a machine's screen or a script's
output, reaches Claude as any other tool's output does.

If vma is missing, the skill points you to guimadaleno.com/vma and installs
vma only with your OK. That download is an ordinary web request to
download.guimadaleno.com.
