vma

Give an AI agent a VirtualBox machine.

The agent sees its screen, uses its mouse and keyboard, and runs scripts and moves files inside it. One small Windows executable: an MCP server for agents, a command line for scripts.

d=$(wslpath "$(powershell.exe -NoProfile -Command '$env:LOCALAPPDATA' | tr -d '\r')")/Programs/vma && mkdir -p "$d" ~/.local/bin && curl -fsSLo "$d/vma.exe" https://download.guimadaleno.com/vma/0.1.0/vma.exe && ln -sf "$d/vma.exe" ~/.local/bin/vma
curl.exe -fsSLo vma.exe https://download.guimadaleno.com/vma/0.1.0/vma.exe; .\vma.exe help

It puts vma.exe on Windows' disk and links it as ~/.local/bin/vma, which a new terminal finds. Then, for Claude Code, claude mcp add vma -- vma mcp, or vma help.

It downloads vma.exe into the folder you are in, and shows its help.

Version 0.1.0, 645 KB, for Windows with VirtualBox 7.2 or a later 7.x. Its SHA-256 is in SHA256SUMS.

For agents

What it does on the command line it does as MCP tools too, with pictures in their results, on MCP 2026-07-28 and the versions before it.

Quick

A picture of the screen in 23 ms, a key in 6, through MCP. Keys go at the pace the machine reads them, so a slow one loses none.

Inside, too

It installs Windows on a new machine with no one at it. Its helper there runs scripts, moves files, and finds windows and buttons by name.
